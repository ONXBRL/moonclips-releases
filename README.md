# MoonClips para Windows

MoonClips ayuda a encontrar, editar y publicar clips a partir de vídeos y directos.

## Descargas oficiales

Consulta las versiones disponibles en [Releases](https://github.com/ONXBRL/moonclips-releases/releases). Cada versión publicada incluye el instalador de Windows, las notas de cambios y el anuncio que consulta MoonClips.

A partir de MoonClips 0.3.5, la aplicación avisa cuando hay una versión más reciente. Las versiones anteriores se actualizan instalando el paquete de Windows desde Releases cuando esté disponible.

MoonClips es software propietario de Onx Dev. Este repositorio aloja únicamente información pública de distribución y los instaladores que se publiquen en Releases. El código fuente de la aplicación es privado.
